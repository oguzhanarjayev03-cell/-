Пароль беріктігін бағалағыш

Жобаның мақсаты

Java бағдарламалау тілі арқылы парольдің беріктігін бағалау және оны жақсарту бойынша ұсыныстар беру.

Негізгі мүмкіндіктері

- Пароль ұзындығын тексеру.
- Үлкен және кіші әріптердің болуын анықтау.
- Сандар мен арнайы таңбаларды тексеру.
- Парольдің беріктігін бағалау.
- Қауіпсіз пароль жасауға ұсыныстар беру.

Қолданылатын технологиялар

- Java
- Maven
- JUnit 5

Қауіпсіздік ескертуі

Бағдарлама оқу мақсатында жасалады. Нақты парольдерді сақтауға арналмаған.
