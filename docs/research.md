Ұйымды зерттеу: Пароль қауіпсіздігі жүйесі

1. Жобаның мақсаты

Бұл жобаның мақсаты — пайдаланушы енгізген парольдің беріктігін бағалайтын Java бағдарламасын жасау. Бағдарлама парольдің қауіпсіздік талаптарына сәйкестігін тексеріп, оны жақсарту бойынша ұсыныстар береді.

2. Зерттелетін ұйым

Жоба университеттің ақпараттық жүйесіне арналған пароль қауіпсіздігін тексеру мысалы ретінде қарастырылады. Университеттің студенттері, оқытушылары және әкімшілері ақпараттық жүйеге кіру кезінде құпиясөздерді пайдаланады.

Бұл жоба нақты университеттің ішкі жүйесін зерттеу емес, университет ортасына арналған оқу жобасы болып табылады.

3. Негізгі пайдаланушылар (акторлар)

- Студент: парольдің беріктігін тексереді.
- Оқытушы: пароль қауіпсіздігі туралы ақпаратты пайдаланады.
- Әкімші: жүйеге қойылатын пароль талаптарын анықтайды.

4. Функционалдық талаптар

1. Пайдаланушы пароль енгізе алады.
2. Бағдарлама пароль ұзындығын тексереді.
3. Үлкен және кіші әріптердің бар-жоғын анықтайды.
4. Сандар мен арнайы таңбалардың бар-жоғын тексереді.
5. Пароль беріктігін ұпаймен бағалайды.
6. Әлсіз парольді жақсарту бойынша ұсыныстар береді.
7. Жиі қолданылатын әлсіз парольдерді анықтауға мүмкіндік береді.

5. Функционалдық емес талаптар

- Бағдарлама Java тілінде жазылады.
- Бағдарлама қарапайым және түсінікті болуы керек.
- Код бірнеше класқа бөлініп, ООП қағидаларына сай ұйымдастырылады.
- Қате енгізулер өңделуі керек.
- Нақты парольдер файлға сақталмауы керек.

6. Қауіпсіздік талаптары

Пароль қауіпсіздігін бағалау кезінде тек ұзындыққа сүйенуге болмайды. Парольдің күрделілігі мен жиі кездесетін парольдер тізімінде болуы да ескеріледі. Бағдарлама оқу мақсатында жасалады және нақты пайдаланушылардың парольдерін жинауға немесе сақтауға арналмаған.

7. Қорытынды

Зерттеу нәтижесінде пароль қауіпсіздігін тексеру жүйесіне қажетті негізгі пайдаланушылар мен функционалдық талаптар анықталды. Бұл талаптар Java бағдарламасын және UML диаграммаларын әзірлеуге негіз болады.
